原 PNG、压缩前备份以及原始制作记录统一存放在 [designs/original-assets/home-mobile-autumn](../../designs/original-assets/home-mobile-autumn/)，不参与发布。reading-kyoto-reference.png 是旧设计参考图，文章卡片现已改用真实文章封面，因此只归档、不上传。
