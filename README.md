## GitHub Pages

完整仓库含听力音频，超过 Pages 的 1 GB 站点限制。因此 scripts/prepare-pages.cjs 会把网页与题库放入 _site，听力 MP3 从同一仓库、同一提交的 raw.githubusercontent.com 读取；不删除音频、不降低音质、不依赖 kijistudy.com。克隆到本地时仍使用本地音频。Pages 页面需联网。

仓库设置中选择 Pages → GitHub Actions 后，可手动运行 Publish selected Kiji to Pages。工作流仅支持手动启动，提交或推送本身不会触发这个工作流。网页发布目录 _site 不要提交。

推送代码与 Pages 发布分开；本仓库附带的发布工作流仅在手动启动时运行。正式网站、后台与正式站缓存不在本仓库的更新范围内。
